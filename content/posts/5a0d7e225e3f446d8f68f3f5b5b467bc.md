# Invariants

**Definition:** Properties that do not change when a process is applied.

- **Goal:** Identify what stays constant during a repetitive process.
- **Consequence:** You can reason about the final state without executing the repetitive process.
- **Method:** Abstract the state into variables $\rightarrow$ Find an invariant $\rightarrow$ Use the invariant to deduce what is possible and what is impossible.

***

## Example: The Empty Boxes Problem

> Eleven large empty boxes are placed on a table. An unknown number of the boxes is selected and into each eight medium boxes are placed. An unknown number of the medium boxes is selected and into each eight small boxes are placed. At the end of this process there are 102 empty boxes. How many boxes are there in total?

***

## Solution

**Goal:** Determine the number of boxes given the number of empty boxes. *(Revised from simply "How many boxes are there in total?")*\
**Variables:** Total boxes (`b`), Empty boxes (`e`)\
**Type:** Integer

### 1. Extract Information

- **Nouns (The Data):**
  - Total boxes (Plural) $\rightarrow$ Var `b`
  - Empty boxes (Plural) $\rightarrow$ Var `e`
  - ~~table~~ *(Inessential wrapper)*
- **Adjectives (The State):**
  - ~~small~~
  - ~~medium~~
  - ~~large~~ *(Inessential aesthetic details)*
- **Verbs (The Actions):**
  - `selected` $\rightarrow$ WHAT? empty boxes
  - `placed` $\rightarrow$ WHERE? inside an empty box
- **Adverbs & Absolutes (The Constraints & Control Flow):**
  - `each` $\rightarrow$ Universal Constraint ($\forall$). Every time the verb happens, the transition rule never changes.
  - `end of this process` $\rightarrow$ Post-condition: `e = 102`

### 2. Algorithmic Architecture

**State variables**: $b$ = total boxes, $e$ = empty boxes.
**Assignment (The Atomic Move):**

```
b, e := b + 8, e + 7
```

**State & Invariant:**
We have abstracted the state into variables `b` and `e`.
Next step is to find the invariant using the formula:

```
E[lhs := rhs] = E
```

***

## Remarks

1. **Goal-Oriented Phrasing:** I started following the goal-oriented approach. So, I blindly copied the ending sentence. The goal should have been explicitly framed as a relationship: *Determine the number of boxes given the number of empty boxes.*
2. **Tunnel Vision on State:** My focus was too narrow. I did not initially think of the state of the *empty* boxes. I put all my focus on trying to count the *total* boxes without asking the crucial question: *"How would `e` change every time the 'verb' happens?"*
